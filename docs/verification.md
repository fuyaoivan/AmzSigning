| 范围 | 结果 |
| --- | --- |
| 首次安装 | 仅显式选择设备的请求允许 App 不存在，构建时传入设备注册授权，验证描述文件后才安装 |
| 自动续签 | 原 App 缺失时停止，不注册另一台设备、不触发首次安装 |
| 绑定提交 | 安装回执及安装后 App 查询通过后才改绑，并恢复成功时间加六天的周期 |
| 安装失败 | 保留原绑定、成功记录和重试时间；手动首次安装不进入自动重试 |
| 多项目 | 每项独立提交，部分成功不改变失败项目的状态 |
| 请求身份 | 离开模式、停用、移除、重新添加及原绑定改变使旧请求失效 |
| 并发设置变化 | 构建期间切换离开模式阻止安装；迟到回执不写入替换项目记录 |
| 指定设备 | 所选设备不在线时停止，不选择其他手机；错误设备回执不能改变绑定 |
| 版本保护 | 拒绝覆盖已有更高版本，也拒绝构建期间新出现的更高版本 |
| 签名与回执 | 有效期不足时不安装，安装后无法查到 App 时不提交绑定 |
| 资源与安全 | 隔离测试目录、构建目录回收；没有卸载或设备文件删除调用 |

构建链测试使用模拟 Xcode、签名及设备接口，覆盖真实安装流程中的状态转换与校验分支，但不等同于实机端到端验证。测试的描述文件缓存为独立空目录，不接触使用者的签名材料。

## Release 与界面

Release 编译、图标打包及 `codesign --verify --deep --strict` 通过。安装程序完整替换本地应用，保留原配置，并删除构建缓存及打包输出。

设置页显示 v1.3.0 和“安装到 iPhone”入口。安装窗口可发现已有配对设备并显示名称、连接方式及标识尾号；设备默认未选中，安装按钮不可用。选择设备后可勾选多个项目；取消所有项目选择后按钮再次不可用。取消窗口不提交安装请求，不改变设备绑定及成功时间。

界面保留一次性安装、安装成功后切换续签设备以及数据恢复边界的必要说明。设备卡片与项目列表具有明确的滚动区域高度，避免窗口按内容布局时裁切控件。

设备发现命令执行前后，项目绑定、成功时间、扫描状态及运行摘要保持一致。持有任务锁时，设备查询和安装请求均返回退出码 75，状态文件不变；连续三次空闲 `tick` 耗时 61.70–67.37 ms，状态文件逐字节保持不变。关闭设置窗口后应用进程退出。

## 真机首次安装与无线连接

2026-11-10 使用已发布的 v1.3.0 应用，在与原绑定设备不同的已配对 iPhone 上完成两个项目的首次安装。安装前通过设备接口确认两个目标 App 均不存在。

新设备最初报告开发者模式关闭，界面禁止提交安装。使用者开启模式、重启并再次确认后，设备详情与所选设备身份一致，开发状态有效；刷新后从设置界面执行“安装并绑定”。

实际构建使用项目既有 Automatic Signing 和 Personal Team，并对显式选择的目标启用设备注册参数。两项均通过签名、描述文件、设备和有效期检查；安装接口及安装后的 App 查询成功，取得 2 个成功、0 个失败的结果。

两个项目的管理标识、Bundle ID、Team 和启用状态保持一致，绑定更新到所选新设备。成功时间依据本次安装结果更新，失败重试期限清除；下一周期为成功时间加六天，日期为 2026-11-16，签名到期日期为 2026-11-17。逐项目提交期间也观察到第一项成功时仅该项完成改绑，第二项仍保留原记录。

安装通过 USB 完成，Xcode 图形界面保持关闭。运行日志中的两条安装命令均指向所选新设备，没有针对旧设备执行安装，也没有卸载或设备数据删除命令。构建和描述文件恢复目录在结束后为空。

拔除 USB 后，设备接口将同一新设备报告为 `localNetwork`；再次通过 Wi-Fi 查询到两个已安装 App。该步骤只验证无线连接与 App 可查询性，没有重复安装，不等同于已经等待六天并完成下一周期续签。手机业务数据未由本工具读取或迁移。

实机验证限于当前 Mac、Xcode、Personal Team 与这台 iPhone，不覆盖其他账号的设备额度、所有系统版本及其他网络环境。既有覆盖续签链路曾于 2026-11-04 通过真实 Wi-Fi 安装验证，调度时间边界由自动测试覆盖。

Apple 登录、双重认证、系统授权、设备信任及开发者模式由使用者完成。工具不保存密码，不自动接受新许可，不取消设备安全要求，也不迁移手机业务数据。

## 资源回收与发布

发布前检查源码、未跟踪的新源码及全部可达 Git 历史，匹配本机项目名称、Bundle ID、Team、设备与描述文件标识、账号邮箱和用户路径，并检查常见令牌及私钥格式。公开内容仅包含通用源码、隔离测试、脚本和技术文档；本地状态、设备查询输出及应用包由忽略规则排除。

交付清理限定于本项目的构建缓存、打包目录、日志、测试数据和临时验证文件，保留正式应用、有效状态及调度配置。共享 Xcode 缓存、账号、钥匙串、签名材料以及手机业务数据不在清理范围内。

新增功能兼容既有状态格式 v2，版本按 Minor 递增至 v1.3.0，构建编号递增至 8。没有新增常驻进程、自动扫描任务或首次安装后台队列。
